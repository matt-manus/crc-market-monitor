05 / METHODS

方法與資料狀態

股票範圍。 普通股及 ADR；系統設計預留 ETF、基金、認股權證、單位及優先股的排除規則。收市價、成交量和成交金額條件會在每日更新程序中重新套用。

技術讀數。 20／50 日線百分比的分母只包括擁有足夠交易日資料的證券；SPY 和 QQQ 讀數使用收市價相對 50 日 EMA 的 14 日 ATR 距離。

領導股。 領導股條件為符合分析股票池、成交金額門檻及相對 63 個交易日前收市價的動量門檻。這是個人研究指標，不是發行指數或交易標的。

資料更新。 GitHub Actions 只在資料完整和品質檢查通過後寫入每日結果；如資料尚未完成，網站保留上一個成功交易日。
